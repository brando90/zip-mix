# ZipMix Experiments

This folder contains the experiments for the Compel-ZipMix project, following the standard agent-config rules for ML research.

## Active Experiments
- `00_related_work`: Literature review and analysis of prior work.
- `01_compression_threshold_buckets`: Analysis and thresholds for compression ratio bucketing.
- `02_alignment_prior_analysis`: Prior alignment and scoring analysis.

## Structure
Each experiment contains its own `README.md` with:
1. Objective
2. Hypothesis
3. Experimental Setting
4. Metric Definition
5. Results
6. Why These Numbers Are Correct
7. Known Limitations
8. Verification Checklist
9. Reproduction
10. Experimental Details
